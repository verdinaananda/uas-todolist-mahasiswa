# Aplikasi To-Do List Mahasiswa

## Deskripsi Aplikasi
Aplikasi To-Do List Mahasiswa merupakan aplikasi sederhana berbasis TypeScript yang dibuat untuk membantu mahasiswa mencatat dan mengelola tugas kuliah. Melalui aplikasi ini, mahasiswa dapat menambahkan tugas, melihat daftar tugas, mengubah tugas, menghapus tugas, dan mencari tugas dengan lebih mudah.
